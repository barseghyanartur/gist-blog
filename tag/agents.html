dot-agents: Skills for AI Agents

2026-05-08 | Tech | python, ai, agents, tooling, open-source

AI agents are only as good as the instructions they are given. dot-agents is a public repository containing a set of SKILL.md files — structured, authoritative procedures that agents like Claude Code or Amazon Q Developer can follow to do real work on a codebase.

Each skill has one job and does it well.

What is a SKILL.md?

A SKILL.md file is a Markdown document with a small YAML header. It defines a policy or procedure in plain, unambiguous language: what the agent MUST do, what it MUST NOT do, and how to verify it is done correctly. No vague suggestions — just enforceable rules.

Skills are invoked by name:

@skill migrate-to-uv
/migrate-to-uv

What skills are included?

The repository currently ships six skills across three areas:

Repository governance

  • repo-bootstrap — creates AGENTS.md and the initial skill structure in a fresh repository.
  • skill-authoring — rules for writing new skills that do not contradict existing ones.

Development workflow

  • update-documentation — detects and fixes mismatches between code and docs, treating code as the source of truth.
  • doc-codeblock-tests — validates Python code blocks in Markdown files by running them through pytest-codeblock. If a user can copy it, it must run.

Python project management

  • migrate-to-uv — full migration from pip, setup.py, or requirements files to a uv-managed pyproject.toml workflow, including Makefile and pre-commit templates.
  • migrate-from-mypy-to-ty — replaces mypy with Astral's ty across all project surfaces: dependencies, config, CI, pre-commit hooks, and docs.

The authority hierarchy

Skills are not all equal. Authority flows top-down:

AGENTS.md  →  existing SKILL.md files  →  new skills

A new skill MUST NOT contradict what is above it. This keeps agent behaviour consistent across a codebase even as the skill set grows.

Why I built it

Every project I maintain accumulates the same governance needs: keep docs in sync, enforce test coverage of code examples, migrate tooling as the ecosystem moves. Writing the same instructions in each repo's AGENTS.md is copy-paste maintenance waiting to rot.

dot-agents centralises those instructions into reusable, versioned skills that any agent — and any developer — can read and trust.

The repository is at github.com/barseghyanartur/dot-agents. MIT licensed.
